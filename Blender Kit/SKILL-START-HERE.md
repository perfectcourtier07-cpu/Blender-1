# Blender Kit skill: how to add it

This ZIP is the second half of the Blender Kit: the skill that teaches Claude how to build and render 3D shots. It needs the Setup (the first ZIP) to be done first.

1. Leave this ZIP where you downloaded it. Don't unzip it, don't drag it into the Blender Kit folder.
2. In Claude Desktop, with your **Blender Kit** folder open, say:

> Install the Blender skill from C:\Users\YOU\Downloads\Blender-Kit-2-Blender-Skill.zip

(Windows: right-click the file, then "Copy as path". Mac: drag the file into the chat box to paste its path.)

Claude copies the skill into the kit folder without touching anything else, and `PROMPTS.md` appears next to `CLAUDE.md`.

3. Make your first shot:

> Make a 5-second 3D title that says MY FIRST 10K, with 10K in gold. Show me stills first.

That's it. More prompts are in **PROMPTS.md**, including how to copy a channel's style for your hook (it needs a few extra free tools; Claude offers to install them the first time).

If Claude says the kit folder is missing, open the folder that contains `CLAUDE.md` and `tools` and try again.

**Already have Blender Kit 1.0?** Download both new zips and say, one after the other:

> Update the kit from C:\Users\YOU\Downloads\Blender-Kit-1-Setup.zip

> Install the Blender skill from C:\Users\YOU\Downloads\Blender-Kit-2-Blender-Skill.zip

Your shots folder stays as it is. Then fully quit and reopen Claude Desktop once.
